# Input Profiles Directory

This directory stores configuration files (in JSON and YAML formats) representing predefined input profiles for testing.

## Profiles Catalog

- `profile_baseline_25m.json`: Default baseline configuration for single-span 25m two-lane bridge.
- `profile_min_span_12m.json`: Boundary profile with minimum span length ($12.0\text{ m}$).
- `profile_max_span_45m.json`: Boundary profile with maximum span length ($45.0\text{ m}$).
- `profile_skew_30deg.json`: Bridge with $+30.0^\circ$ skew angle.
- `profile_custom_materials.json`: Comprehensive custom steel and concrete parameter set.
- `profile_multi_lane_wide.json`: 4-lane wide carriageway configuration ($14.0\text{ m}$).
