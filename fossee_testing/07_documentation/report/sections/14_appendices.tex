\section{Appendix B: Automation Script Listings}
Key automation scripts located in \texttt{06\_automation\_scripts/} are detailed below:
\begin{itemize}
    \item \texttt{compare\_dictionaries.py}: Implements recursive dictionary traversal with configurable absolute and relative numerical tolerances.
    \item \texttt{validate\_inputs.py}: Interfaces directly with \texttt{BridgeInputValidator} and \texttt{validate\_osi\_inputs()} for batch verification of \texttt{.osi} project files.
    \item \texttt{generate\_test\_summary.py}: Parses CSV registers and computes execution rate, pass percentage, and executive Markdown metrics.
\end{itemize}
