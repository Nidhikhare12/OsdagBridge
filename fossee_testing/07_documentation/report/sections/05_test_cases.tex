\section{Basic Input Verification Cases}
Basic inputs are governed by \texttt{BridgeInputValidator.validate\_basic\_inputs}. Key validations include:
\begin{itemize}
    \item \textbf{Span Limits}: Minimum $12.0\text{ m}$, maximum $45.0\text{ m}$. Values outside this window trigger validation alerts and prevent invalid FEA runs.
    \item \textbf{Carriageway Width}: Evaluated under IRC:5:2015 Clause 104.3.1. Bridges without a median require minimum widths based on intended lane counts ($4.25\text{ m}$ single-lane, $7.5\text{ m}$ two-lane).
    \item \textbf{Skew Angles}: Restricted to $[-60^\circ, +60^\circ]$ as per IRC:24 provisions for conventional plate girder layouts.
\end{itemize}
