# OsdagBridge Software Testing & Issue Reporting

## Objective
The objective was to test the OsdagBridge short-span steel girder bridge module and verify the complete workflow from GUI input to final design report generation.

## Environment

Operating System: macOS  
Application: OsdagBridge  
Testing Type: Functional Testing

## Testing Workflow

1. Launch OsdagBridge application.
2. Enter bridge design parameters.
3. Execute bridge design calculation.
4. Verify generated structural outputs.
5. Verify 3D visualization.
6. Generate final PDF design report.
