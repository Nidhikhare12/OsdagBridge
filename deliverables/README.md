# Report generation deliverables

| File | Description |
|------|-------------|
| `Report_Before.pdf` | Baseline output produced from the unmodified `dev` branch. |
| `Report_After.pdf` | Enhanced output after the refactoring described in `docs/REPORT_ENHANCEMENTS.md`. |
| `Report_Before.tex`, `Report_After.tex` | Corresponding LaTeX sources (useful for diffing header repetition). |
| `Report_From_GUI.pdf` | Generated by driving the real GUI report path (`ReportOptionsDialog` → QThread worker → `generate_design_report`) via `scripts/gui_smoke_test.py`. |
| `Report_Real_Design.pdf` | Full report from a **real OpenSees analysis + design** (4 girders, 30 m span) via `scripts/run_full_design_test.py`. Used to verify the Page 30 / G4 footer-overlap case. |
| `Technical_Report.pdf` | 10-page primary submission report (pdflatex): requirements, files, style architecture, verification, performance/GPU study, cross-app colour checks, critical assessment and reproduction commands. |
| `Technical_Report_LO.pdf`, `Technical_Report_LO.html` | Alternate LibreOffice Writer/Web export with the same green/shaded format. Note: LibreOffice downsamples embedded figures to 96 ppi JPEG, so the pdflatex PDF is the higher-fidelity primary version. |
| `report_assets/` | Page renders used as figures in the technical report. |
| `../docs/BENCHMARK.md` | Baseline vs enhanced timing/size benchmark and full-solver run metrics. |
| `gui_window.png` | Screenshot of the real OsdagBridge desktop window (PySide6), captured during the visible GUI test. |
| `Report_Real_UI.pdf` | 60-page report generated by **clicking the real Design and Generate Report buttons** in the GUI (`scripts/gui_real_ui_test.py`), from 1001 real design output keys. |
| `gui_after_design.png`, `gui_after_report.png` | GUI screenshots after the Design click and after report generation. |

Both PDFs were generated from the **same representative payload** with
`scripts/generate_sample_reports.py`; no GUI or OpenSees analysis is required.

Quick checks on the enhanced report:

```bash
grep -c '\\endhead' deliverables/Report_After.tex   # 50 (baseline: 2)
grep -n 'fig:ur-summary|fig:material-quantities' deliverables/Report_After.tex
```
