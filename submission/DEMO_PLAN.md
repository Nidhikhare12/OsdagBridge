# Demonstration plan

Aim for a three-minute recording with the actual desktop app and the supplied PDFs.

| Time | Show |
| --- | --- |
| 0:00–0:25 | Open OsdagBridge, load `test-design.osi`, and show the span and carriageway width. |
| 0:25–0:55 | Click Design. Use a clearly marked cut while the real analysis runs. Return at 100%, with the design log and the failing girder check visible. |
| 0:55–1:20 | Generate a report with all sections, figures and TOC. Show the finished PDF and its file date. |
| 1:20–1:50 | Compare the preserved baseline and enhanced report. Show the split stiffener rows and footer, the single summary header, repeated continuation headings and millimetre dimensions. |
| 1:50–2:20 | Show Chapter 3's separate tables and compare the alternate footpath input. Show the Chapter 5 status chart and the red 1.0 line. Explain the missing diaphragm design data. |
| 2:20–2:45 | Show Chapter 7 material quantities and the labeled reinforcement estimate. |
| 2:45–3:00 | Show the test output and the evidence bundle. |

The package contains genuine application-produced PDFs, report images and run logs. A screencast and personal application documents are separate deliverables.
