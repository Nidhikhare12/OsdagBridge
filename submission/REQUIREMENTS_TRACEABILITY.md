## Result provenance and gaps

- Chapter 2 dimensions come from the design-normalized input dictionary. G1 depth is 1.67 m, web thickness 0.01 m and flange width 0.51 m. The table displays 1670, 10 and 510 mm.
- The old executive outcome list was a set of literal pass claims. The current list derives each outcome from the same checks as the chart. Chapter 5 continues to display engineering checks independently of the chart.
- The largest deck ratio is `deck_design_results.ur_composite_crack`. The 0.938 overhang flexure ratio is a different check. The previous report used the stored `Member.efficiency`, whose governing denominator was not identified.
- The historical diaphragm figures reused cross-bracing check data. The actual `end_diaphragm_design_results` contains three empty pair results and the BOQ supplies no diaphragm steel quantity. The report exposes both gaps.
- The GUI describes custom footpath pressure in kN/mm². The report identifies it as an input and the automatic pressure as an IRC reference. The analyser's footpath load path calls `footpath_dead_load_kN_m2()`. Braking and centrifugal force magnitudes are absent from the captured results. The existing lane-only braking helper cannot establish applied force from this run and has uninitialized branches for the two-lane case.
- Wind reference speed and pressure can come from IRC 6 Table 12. Missing wind and seismic force outputs are explicitly marked. The application still emits thermal load case warnings.

Current correction: Osdag exports member efficiency but does not identify its governing denominator. The installed compression design assigns it using member compression capacity and also connection capacity at different stages. The report displays the stored efficiency separately and marks the verified cross-bracing ratio unavailable.
